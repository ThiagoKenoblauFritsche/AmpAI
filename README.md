# ⚡ AmpAI — Assistente de Engenharia Elétrica Avançada

O **AmpAI** é uma plataforma SaaS dedicada ao mercado de engenharia elétrica, oferecendo automação de cálculos complexos e geração de memoriais técnicos em conformidade estrita com normas internacionais **IEC (International Electrotechnical Commission)**, utilizando o Sistema Internacional de Unidades (SI).

---

## 🚀 Arquitetura do Ecossistema de IA

O projeto é sustentado por uma governança multi-agentes de IA especializada:

1. **CEO (Orquestrador):** Responsável por estratégias, análise de mercado e validação de produto.
2. **Engenheiro Eletricista Sênior:** Especialista em física e conformidade com normas IEC.
3. **CTO:** Arquiteto de software, governança tecnológica e integrações de dados.
4. **Desenvolvedores Seniores:** Foco em C# (.NET), Python (NumPy/Pandas) e TypeScript (React).
5. **Senior QA-Security:** Auditor de segurança e testes de resistência de código.

---

## 🛠️ Módulos da Plataforma

- **⚡ Curto-Circuito Trifásico Simétrico:** Cálculos analíticos em transformadores industriais usando **IEC 60909**.
- **🔌 Dimensionamento de Cabos BT e MT:** (Em breve) Capacidades de condução de corrente e queda de tensão.
- **⛰️ Derating por Altitude:** (Em breve) Correções térmicas e dielétricas acima de 1000m.

---

## 💻 Tecnologias Utilizadas

- **Front-End:** HTML5, Tailwind CSS, Chart.js.
- **Back-End:** C# (.NET), Python (NumPy/Pandas).
- **Lógica e Localização:** JavaScript com formatação pt-BR.
- **Provedor de IA:** OpenRouter para modelos de linguagem avançados.
