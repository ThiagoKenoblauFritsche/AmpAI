Passo 1 Corrente Nominal Secundária do Enrolamento

Calculada com base na potência aparente nominal ($S_{nT}$) e tensão nominal secundária entre fases ($U_{nT}$):

InT = SnT / (√3 · UnT)
InT = -- A
Passo 2 Impedância Equivalente da Rede de Média Tensão

A reatância é obtida a partir da potência Scc de curto-circuito de referência e tensão nominal, assumindo relação $R/X = 0.1$:

ZQ = (c · UnT²) / Scc
ZQ = -- Ω
XQ = 0.995 · ZQ = -- Ω
RQ = 0.1 · XQ = -- Ω
Passo 3 Impedâncias de Sequência Positiva e Zero do Transformador

Mapeada via reatância de curto-circuito (Z%) e perdas de Joule no cobre em regime de carga nominal ($P_{cu}$):

ZT = (Z% / 100) · (UnT² / SnT)
ZT = -- Ω
RT = Pcu · UnT² / SnT²
RT = -- Ω
XT = √(ZT² - RT²) = -- Ω

A impedância de sequência zero ($Z_{(0)T}$) é estimada de acordo com o grupo de ligação do enrolamento secundário (Dyn11):

Fatores Dyn11
R0T = -- Ω | X0T = -- Ω
Passo 4 Somatório de Impedâncias Equivalentes de Loop
R(1) = RQ + RT = -- Ω
X(1) = XQ + XT = -- Ω
Z(1) = √(R(1)² + X(1)²) = -- Ω
R(0) = R0T + 3·RN = -- Ω
X(0) = X0T + 3·XN = -- Ω
Z(0) = √(R(0)² + X(0)²) = -- Ω
Passo 5 Resoluções Analíticas Finais (IEC 60909)
1. Curto-Circuito Trifásico Simétrico Inicial (I''k3):
I''k3 = c · UnT / (√3 · Z(1))
I''k3 = -- kA

2. Curto-Circuito Bifásico Livre de Terra (I''k2):

I''k2 = -- kA

3. Curto-Circuito Monofásico Terra Inicial (I''k1):
I''k1 = (√3 · c · UnT) / |2·Z(1) + Z(0)|
